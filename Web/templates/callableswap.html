03 / G2++ SHORT RATE

경로의 금리는
세 조각의 합으로 읽습니다

r(t) = phi(t) + x(t) + y(t)

dx = −a·x·dt + sigma·dW₁
dy = −b·y·dt + eta·dW₂
corr(dW₁, dW₂) = rho

이 파일은 x와 y를 새로 시뮬레이션하지 않고, simulation dictionary에서 읽습니다.

short ratetime
0call 1call 2maturity

phi는 시장 커브를 붙잡고, x/y는 미래 금리의 확률적 움직임을 제공합니다.

short_rates = x_paths + y_paths + phi[np.newaxis, :](n_paths, n_times) broadcasting으로 전 경로를 한 번에 생성
04 / CUMULATIVE DISCOUNTING

할인은 매번 적분하지 않고
누적값의 비율로 재사용합니다

INPUTr[path, time]

각 경로의 단기금리. trapezoidal rule로 시간구간 적분

→
CACHEI(0,t)

경로별 누적 적분을 한 번만 계산

→
QUERYDF(i,j)

exp(−(I(0,j) − I(0,i))) = DF(0,j) / DF(0,i)

increments = 0.5 × (r[:, :-1] + r[:, 1:]) × dt
cumulative_integral[:, 1:] = cumsum(increments, axis=1)
cumulative_df = exp(−cumulative_integral)

이 최적화가 뒤의 fixed leg, floating leg, continuation discount, valuation-date discount를 모두 지탱합니다.

05 / SWAP VALUE

콜일의 스왑 가치는
두 레그의 현재가치 차이입니다

LEGCODE IDEAFINANCIAL MEANING
FIXEDfixed_rate × accrual × notional × P(call, pay)미래 고정 쿠폰을 콜일 기준으로 할인
FLOATING(forward + spread) × accrual × notional × P(call, pay)P(call, start) / P(call, pay)로 forward 생성
SWAPfixed_pv − floating_pvReceiver의 관점. Payer는 부호를 반전
L_fixed = Σ K · alphaᵢ · N · P(t, Tᵢ)
L_float = Σ [(P(t, Sᵢ) / P(t, Tᵢ) − 1) / tauᵢ + spread] · tauᵢ · N · P(t, Tᵢ)
V_swap(t) = L_fixed − L_float   (RECEIVER)
floating leg에서 forward와 discount가 같은 경로의 cumulative DF에서 나오므로, 모델의 금리 상태와 현금흐름 평가가 일관됩니다.

07 / EXERCISE PAYOFF

콜 권리는
스왑 가치의 부호로 결정됩니다

이 구현에서 call right는 receiver 또는 payer입니다. 같은 swap position이라도 누가 권리를 행사하는지에 따라 유리한 방향이 달라집니다.

UNDERLYING SWAPV_swapReceiver: fixed − floating
Payer: floating − fixed
→
EXERCISE VALUEmax(benefit, 0)자기 포지션을 종료하거나
상대방에게 종료를 요구하는 권리
call_right = RECEIVER
receiver_payer == RECEIVER → max(−V_swap, 0)
receiver_payer == PAYER   → max(V_swap, 0)

call_right = PAYER도 같은 논리로 자신의 불리한 포지션을 반대 방향에서 읽습니다.
이 단계의 반환값은 아직 오늘의 가격이 아닙니다. 각 콜일에 “그때 행사하면 얻는 가치”를 저장한 exercise_values 행렬입니다.
08 / LSM REGRESSION

미래의 선택 가치를
현재 상태에서 추정합니다

Longstaff-Schwartz는 실제로 미래 경로를 모두 아는 것이 아니라, 현재의 상태변수 x, y가 주어졌을 때 continuation value의 조건부 기대값을 회귀로 근사합니다.

1xyx²x·yy²

A · beta ≈ continuation_value
continuation_estimate = A · beta

점: 경로별 미래가치 · 선: 상태변수 기반 조건부 추정치

A = [1, x, y, x², x·y, y²]
beta = np.linalg.lstsq(A, continuation_value)
estimate = A @ beta
경로 수가 basis 차원보다 작으면 평균 continuation value를 사용합니다. 이는 회귀가 불안정해지는 작은 샘플의 fallback입니다.

10 / TODAY'S PRICE

행사된 payoff를 오늘로 가져와
경로 평균을 냅니다

PATHWISE VALUEPVₚ선택된 콜일의 option value × DF(call, today)
MONTE CARLO PRICEmean(PVₚ)경로별 현재가치의 산술평균
STATISTICAL ERRORσ / √N표본 표준편차로 standard error 계산
present_values[exercised_mask] = option_values × cumulative_df[path, selected_call] / cumulative_df[path, 0]
price = np.mean(present_values)
95% CI = price ± 1.96 × standard_error
결과의 핵심은 가격 하나만이 아닙니다. 경로별 PV, 행사일 인덱스, 콜일별 exercise statistics가 함께 반환되어 모델의 결정을 진단할 수 있습니다.

12 / ZERO COUPON VARIANT

같은 엔진으로
Zero Coupon Callable Bond도 가격화합니다

BOND VALUE

상환액과 콜 가격

만기 상환액은 notional × (1 + rate)^t로 만들고, 콜일의 accrued value를 행사 가격으로 사용합니다.

B(T) = N(1 + z)τ(trade,T)
CallPrice(t) = N(1 + z)τ(trade,t)
OPTION LOGIC

straight bond와 비교

콜일의 straight bond value와 call price를 비교하고, continuation estimate보다 call price가 낮으면 발행자가 상환합니다.

Callable = min(straight value, call price)
Option value = straight price − callable price
swap 버전은 exercise payoff를 별도로 계산하지만, zero-coupon 버전은 채권 가치와 call price의 최소값을 backward induction하는 구조입니다.
13 / REVIEW NOTES

이 코드에서 읽어야 할
금융공학적 가정

MODEL ASSUMPTIONS

무엇을 가정하는가

G2++ short-rate paths가 위험중립 평가에 적합하고, deterministic shift phi가 초기 커브를 맞춘다고 봅니다. 현금흐름은 pathwise discount factor로 평가합니다.

NUMERICAL ASSUMPTIONS

무엇이 근사인가

날짜를 uniform grid index로 반올림하고, 할인 적분은 trapezoidal rule을 사용합니다. LSM continuation value는 제한된 polynomial basis로 근사합니다.

DIAGNOSTICS

무엇을 점검할까

call index가 중복되지 않는지, maturity가 simulation horizon 안에 있는지, 행사 비율이 비정상적으로 0% 또는 100%에 몰리지 않는지 봅니다.

PERFORMANCE

무엇을 빠르게 했는가

cumulative DF 캐시, 사전 계산된 schedule index, NumPy broadcasting, 행렬 LSM으로 반복 계산을 줄였습니다.

CallableSwap.py가격 숫자보다 먼저, 시간축·부호·조건부 기대값의 의미를 검증
